# Andallo MVP

Interactive multi-role prototype for service discovery and ordering.

The public source intentionally omits hardcoded demo accounts. Local registration can demonstrate the customer flow, but provider/admin demo login requires a separate local development setup. Authentication and payments are simulations and must not be used for real transactions. Do not deploy this code as a production marketplace without replacing the demo authentication and payment flows.

## Main flows

- Browse, search, filter, and sort providers by live location, city, radius, price, or rating.
- Compare the price, rating, distance, and service area of up to three providers in the same category.
- View provider details, make a simulated booking, and continue to chat.
- Use customer, provider, and admin demo dashboards.
- Register, verify, log in, update booking status, submit reviews, and contact support in demo mode.

All accounts, providers, payments, offers, messages, and transactions are simulations.
